# Odin Recipes

A basic recipe website built as part of [The Odin Project](https://www.theodinproject.com) 
Foundations course. This project focuses on practicing core HTML skills before 
CSS styling is introduced in later lessons.

## About

This is a simple multi-page website with:
- A home page (`index.html`) linking out to several recipe pages
- Individual recipe pages, each including an image, description, 
  ingredients list, and step-by-step instructions

## Skills practiced

- Structuring a multi-page website with proper file/folder organization
- Writing semantic HTML boilerplate
- Linking between pages using relative paths
- Using ordered and unordered lists
- Embedding images
- Using Git and GitHub for version control
- Publishing a static site with GitHub Pages
